# MIRAGE

> Faking one person is cheap. Faking ten thousand independent people isn't.

MIRAGE is a live Sybil-resistance system for networks under attack by AI agent
swarms. Every fake account looks ordinary on its own; together they are a
mirage. MIRAGE finds the groups of accounts that are too correlated to be
independent people, and changes the network's rules so a detected swarm's
voting weight collapses toward one.
